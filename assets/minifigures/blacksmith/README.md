# Blacksmith — Minifigure Concept

Generated unpainted gray resin tabletop miniature concept. 32mm heroic scale, 25mm round base, 25µm layer-friendly geometry.

Concept: heavy leather apron, hammer raised over anvil accessory on base, soot-stained arms, muscular build.
