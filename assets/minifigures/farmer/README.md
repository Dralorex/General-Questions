# Farmer — Minifigure Concept

Generated unpainted gray resin tabletop miniature concept. 32mm heroic scale, 25mm round base, 25µm layer-friendly geometry.

Concept: pitchfork, straw hat, simple tunic, tired but sturdy pose.

| Image | Notes |
|---|---|
| [`farmer-v1.png`](farmer-v1.png) | First pass. Front three-quarter view, product reference photo style. Pitchfork resting on shoulder. |

Print note: pitchfork tines should be thickened to ~0.6mm for resin printing.
