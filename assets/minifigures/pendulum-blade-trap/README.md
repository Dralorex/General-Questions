# Pendulum Blade Trap — Terrain Concept

Generated unpainted gray resin tabletop scatter terrain. 32mm tabletop scale, 25µm layer-friendly geometry.

Concept: floor-marker pressure plate for a pendulum blade trap. Looks like a normal dungeon tile with a subtle seam; a faint crescent-arc scratch hints at a swinging blade for a knowledgeable trap finder — not an obvious scythe model.
